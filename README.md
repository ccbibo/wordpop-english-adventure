# 單字奇遇記 · WordPop

**把英文，玩成一個故事。** 圖像、英文、繁體中文混搭的單字家族三消遊戲。

![Word Pop 產品插畫，並非遊戲截圖](docs/assets/word-pop-cover.svg)

![Version](https://img.shields.io/badge/version-0.3.1-E08244?style=flat-square)
![Node](https://img.shields.io/badge/Node.js-26%2B-3A2C5C?style=flat-square)
![JavaScript](https://img.shields.io/badge/Vanilla-JavaScript-F4D676?style=flat-square)
![SQLite](https://img.shields.io/badge/storage-SQLite-3A2C5C?style=flat-square)

從動物園出發，走過水果、交通、住屋與職業等 20 個主題。每個單字都有三種樣子：圖片提示、英文拼寫、中文意思。只要同一個單字家族，任意組合連成橫向或直向三格以上，就能消除。

例如：**🐱 ＋ cat ＋ 貓 ✅**、**cat ＋ cat ＋ 🐱 ✅**。

包含完整單人流程、帳號與排行榜、多人房間，以及獨立產品展示頁。這是一個可自行啟動的程式專案，GitHub 儲存庫本身不是已部署的多人遊戲服務。

## 產品亮點

- **一個字，三種連結**：圖像、英文、中文依單字家族混搭，不限定同類型方塊。
- **20 個主題、80 個挑戰**：每章 3 個一般挑戰與 1 個 Boss，使用 5×5 或 6×6 棋盤。
- **完整故事冒險**：首頁、主題地圖、預覽、載入、棋盤、勝敗與解鎖；四位可選夥伴沿小路移動。
- **連續棋盤動畫**：交換、局部消除粒子、掉落、補格與特殊方塊連鎖；英文單字保持單行。
- **邀朋友一起玩**：1v1 計分對戰、2–4 人共同消除目標、邀請連結、代碼與房間密碼。
- **留下學習紀錄**：收藏、小測驗、成長書籤、CSV 匯出與 JSON 備份。
- **黃色童話書頁**：奶油黃、鵝黃與紫墨線條；Fraunces / Inter 英文、Noto Serif TC / Noto Sans TC 中文。

## 快速開始

### 執行環境

- **Node.js 26 或以上**，實測 Node.js 26.0.0；使用內建 `node:sqlite`。
- 新版 Chrome、Edge、Safari 或 Firefox。
- 本機版不需安裝第三方 npm 套件，也不需 AI API Key。

```bash
git clone https://github.com/ccbibo/wordpop-english-adventure.git
cd wordpop-english-adventure
npm start
```

私人儲存庫需使用獲授權的 GitHub 帳號下載。也可透過 **Code → Download ZIP** 解壓縮，再在專案目錄執行 `npm start`。使用 nvm 的人可先執行 `nvm install`、`nvm use`。

## 怎麼玩

### 單人冒險

1. 點「翻開故事目錄」，在地圖點選主題，角色會沿路前往該章節。
2. 在章節側邊選擇挑戰，查看單字、目標與步數。
3. 點「開始冒險」，進入棋盤。
4. 滑動交換兩個相鄰方塊，或依序點選兩格交換。
5. 同一家族橫向或直向連成至少 3 格即可消除；圖像與文字可混搭。
6. 在步數用完前完成收集、解冰或解鎖目標，收下星星並前往下一挑戰。

無效交換會回彈，**不扣步數**；沒有合法交換時會重排。正式冒險依進度解鎖。「先練習，不計分」可探索各主題第一個挑戰，不解鎖進度、不發硬幣，也不上榜。

### 鍵盤操作

| 操作 | 按鍵 |
| --- | --- |
| 移動棋盤焦點 | 方向鍵 |
| 選取方塊 | Enter |
| 與相鄰方塊交換 | Shift + 方向鍵 |
| 關閉可關閉的彈窗 | Esc |

### 特殊方塊與障礙

| 機制 | 觸發或效果 |
| --- | --- |
| 直線閃電 | 4 連生成，觸發時清除整行或整列 |
| 彩虹萬能 | 5 連生成，交換後清除相同家族 |
| 炸彈 | 兩條有效三連交叉成 L / T，至少 5 格，觸發 3×3 消除 |
| 幸運星 | 消除後機率出現，觸發後自動執行 3 次合法配對 |
| 冰塊 | 鄰近成功消除兩次，解除兩層冰塊 |
| 鎖鏈 | 鄰近成功消除一次，解除鎖鏈 |

另提供發音、提示、重排等工具。多人挑戰關閉提示與重排加成。單人失敗時可使用該局的一次免費加五步機會。

## 對打與組隊

### 房主：建立與邀請

1. 進入「同行對戰」，點「建立房間」。
2. 填暱稱、房間名稱，選擇 **1v1** 或 **2–4 人組隊**。
3. 視需要設定房間密碼，再建立房間。
4. 點「複製邀請連結」，自行貼到與朋友的聊天中；密碼另外告訴朋友。
5. 等至少 2 位玩家進房後，由房主點「大家都到了，開始挑戰」。

### 隊員：三種加入方式

- **開啟邀請連結**：直接填寫暱稱與房間密碼（若有）。
- **貼上房間代碼**：在「同行對戰」貼上代碼或完整連結，點「加入朋友」。
- **等待房間列表**：找到朋友的房間，點「加入挑戰」。

多人房間用暱稱即可加入，**不要求先註冊玩家 ID**。邀請連結只有公開房間識別碼，不包含登入或房主憑證。剪貼簿不可用時會選取連結供手動複製。

| 模式 | 人數 | 目標 |
| --- | --- | --- |
| 1v1 友善對戰 | 2 | 兩分鐘內比總分，可能平手 |
| 組隊挑戰 | 2–4 | 兩分鐘內共同消除 120 格，達標可提早結算 |

相同起始種子、獨立棋盤，各自操作。**目前多人固定動物園主題、6×6 棋盤**。房間額滿或開始後不能再加入；等待房間有效兩小時。等待中離開會釋放名額，房主離開則轉移給剩餘隊員；空的等待房間自動移除。

### 另一台手機或電腦怎麼加入？

1. 兩台裝置接到同一個區域網路，讓一台電腦執行 `npm start` 並保持運作。
2. 找出該電腦的區域網路 IP，例如 `192.168.1.20`（請換成實際 IP）。
3. **房主與隊員都從 `http://192.168.1.20:8773/` 開啟遊戲**。房主從這個網址建房，邀請連結才會使用可連線的主機位址。
4. 若無法連線，檢查是否同網段、防火牆是否允許 Node 服務，以及 Wi-Fi 是否隔離裝置。

`127.0.0.1` / `localhost` 只代表目前裝置，不能直接傳給另一台電腦。不同網路的朋友需要雙方都能到達的共用伺服器。上方遠端入口目前是私人存取；跨網路朋友仍須先獲得網站存取權。

同一台電腦試玩可用兩個視窗；若要同時測試兩個不同帳號，請用一般與無痕視窗，或不同瀏覽器，避免共用登入 Cookie。

## 帳號與排行榜

1. 點頁面上方「登入 / 註冊」，選「建立新 ID」。
2. 玩家 ID 使用 3–24 個英文字母、數字或底線；依表單要求設定密碼、暱稱與年級分組。
3. 可在帳號頁自行開啟「讓我的暱稱出現在排行榜」。
4. 登入後完成正式冒險，分數才會送至排行榜；訪客與自由練習不計入。

提供全服總榜、本週主題榜、同年級分組。**每人每關只計最佳成績**，重玩不會讓同一關無限累加。公開榜只顯示選擇公開的玩家暱稱。

本版使用玩家 ID 登入，尚無電子郵件驗證或忘記密碼功能。換裝置必須連到同一後端，帳號與進度才相通。

## 程式結構與開發

```bash
npm test          # 建置並執行重點回歸測試
npm run build     # 將靜態資產與 API 打包成 Worker
```

| 路徑 | 用途 |
| --- | --- |
| `dist/product.html` | 產品展示頁與互動配對示意 |
| `dist/app.js`、`dist/style.css` | 遊戲頁面、互動與視覺 |
| `dist/engine.js` | 三消、特殊方塊、障礙與棋盤邏輯 |
| `dist/words.js` | 20 主題單字家族 |
| `dist/accounts.js`、`dist/schema.js` | 帳號前端與存檔驗證 |
| `server-v2.mjs`、`storage.mjs` | 本機 HTTP 服務與 SQLite 適配 |
| `worker/api.js`、`drizzle/` | 共用 API 與版本化資料庫遷移 |
| `scripts/`、`tests/` | 建置與自動測試 |

測試涵蓋配對引擎、動畫 DOM 模型、進度、單字內容、帳號、SQLite、D1、房間、計分、並行加入與邀請輸入。重點測試不代表逐關真人試玩或學習成效驗證。

### 資料怎麼保存？

- 訪客進度：目前瀏覽器的 localStorage。
- 本機帳號、進度與房間：首次啟動自動建立 `.data/game.sqlite`，不納入 Git。
- Worker 架構：API 支援 D1 介面，遷移位於 `drizzle/`；需另行配置實際託管環境。
- `dist/server/` 是可重新產生的建置輸出，不上傳 Git。

**GitHub 上傳不等於後端上線。** GitHub Pages 只能提供靜態頁，不能執行本專案的 SQLite 帳號與多人 API。跨網路公開遊玩需另外部署具後端與資料庫的服務。

## 常見問題

<details>
<summary>啟動時找不到 node:sqlite？</summary>

先執行 `node -v`，確認使用 Node.js 26 或以上，再執行 `npm start`。
</details>

<details>
<summary>8773 連接埠已被使用？</summary>

先確認是否已有伺服器在運作。也可指定另一埠：macOS / Linux 使用 `PORT=8774 npm start`；PowerShell 使用 `$env:PORT=8774; npm start`，再開啟 8774 網址。所有玩家需連同一服務。
</details>

<details>
<summary>多人頁顯示沒有連上伺服器？</summary>

請從 `npm start` 的網址開啟，不要只用靜態檔案伺服器或 GitHub Pages 取代後端。確認執行服務的終端機仍開著，再重新檢查連線。
</details>

<details>
<summary>邀請連結或密碼不能用？</summary>

確認雙方使用相同服務網址。房間可能已開始、額滿或過期；若有密碼，需另向房主取得。不同服務的代碼不能互通，請開啟朋友的原始邀請連結。
</details>

<details>
<summary>排行榜為什麼沒有我？</summary>

需登入、開啟暱稱公開，並完成正式冒險。自由練習與訪客不上榜；相同關卡只保留最佳成績。若同步失敗，依畫面提示保持連線後再挑戰。
</details>

<details>
<summary>可以離線嗎？</summary>

首次載入需要網路。瀏覽器支援並完成 Service Worker 快取後可玩單人。帳號同步、排行、房間與遠端圖像需要網路，完整離線字體與語音不保證可用。
</details>
